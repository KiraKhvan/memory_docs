# memory_docs

Документы владельца платформы «Очаг»: доменная модель (`domain_model`), архитектура — схемы C4 (`architecture`), ADR доменной модели (`context/adr`), исследования (`research`). `context/CLAUDE.md` — исходная сводка проекта, при расхождении правы документы и этот файл.

## Таблицы

Идентификатор любой таблицы — `uuid`, без исключений: у сущностей, справочников и связующих таблиц. Ссылка на другую таблицу — всегда на её `id` (`uuid`): не на код, не на имя, не на другой столбец. Естественный ключ (код роли, имя хоста) — отдельный уникальный столбец. Исключение — таблицы, которые создают фреймворки (`spring_session` Spring Session, `oauth2_authorization` Spring Authorization Server): их устройство задаёт фреймворк.

Логику пишем в коде, а не в базе: без триггеров, хранимых функций и каскадных удалений. База держит только ключи, ссылки, уникальность и изоляцию мемориалов (RLS). Исключение — только отдельным решением.

## Коммиты

Сообщение начинается с номеров ADR и спеки, к которым относится изменение, затем двоеточие и текст: `ADR 0002: Host resolution rules`. Несколько — через запятую, сначала ADR, потом спеки. Ни к ADR, ни к спеке (правка доменной модели, исследований, этого файла) — без префикса.

# memory_docs

Документы владельца платформы «Очаг»: доменная модель (`domain_model`), архитектура — схемы C4 (`architecture`), ADR доменной модели (`context/adr`), исследования (`research`). `context/CLAUDE.md` — исходная сводка проекта, при расхождении правы документы и этот файл.

## Коммиты

Сообщение начинается с номеров ADR и спеки, к которым относится изменение, затем двоеточие и текст: `ADR 0002: Host resolution rules`. Несколько — через запятую, сначала ADR, потом спеки. Ни к ADR, ни к спеке (правка доменной модели, исследований, этого файла) — без префикса.

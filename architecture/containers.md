# Контейнеры платформы (C4, уровень 2)

![Контейнеры платформы «У истока»](containers.svg)

Схема C4 уровня контейнеров: из каких отдельно запускаемых программ и хранилищ состоит платформа и кто к кому обращается. «Контейнер» здесь — программа или хранилище, не Docker. Пунктир — запланировано.

## Наши контейнеры

| Контейнер | Что делает | Состояние |
|---|---|---|
| Фронт (Next.js) | Сайты мемориалов | работает |
| gefest (Spring Boot, REST API) | Мемориалы, разделы, контент, медиа; дальше — участие и права: `Membership`, `Audience`, `AccessGrant`, `Invitation`, `AccessRequest` | работает |
| БД gefest (Postgres) | Данные gefest, изоляция мемориалов через RLS | работает |
| Сервис авторизации (`auth.у-истока.рф`) | «Кто ты»: `Person`, `AuthIdentity`, сессии, `ApiToken`; вход через VK ID и Telegram, выдаёт токены | планируется |
| БД авторизации (Postgres) | Данные сервиса авторизации | планируется |
| MCP-сервер | Инструменты для агентов; в gefest ходит через REST API с токеном человека, как фронт | планируется |
| Боты Telegram и VK | Приём сообщений + языковая модель + MCP-клиент | планируется |

## Внешние системы

| Система | Зачем |
|---|---|
| Claude, ChatGPT | Внешние агенты: подключаются к MCP-серверу, вызывают его со своих серверов |
| Telegram, VK | Мессенджеры: передают сообщения ботам и принимают ответы |
| Языковая модель | Для ботов, не выбрана: Claude и ChatGPT по API из России недоступны |
| S3 Timeweb | Фото и видео |
| VK ID, Telegram | Вход |

## Связи, не нарисованные на схеме

- **Вход на сайт.** Фронт отправляет браузер в сервис авторизации, тот возвращает его на мемориал с одноразовым кодом (`../domain_model/vk-login-pkce.md`).
- **Файлы.** Фото и видео браузер берёт прямо из S3 по временным ссылкам, которые выдаёт gefest.
- **Токен внешних агентов.** Claude и ChatGPT получают токен у сервиса авторизации через OAuth.
- **Проверка токенов.** gefest и MCP-сервер проверяют токены ключами сервиса авторизации. Стрелка gefest → сервис авторизации — получение этих ключей.

## Не решено

- База сервиса авторизации: отдельный Postgres или отдельная схема в том же.

Решения по авторизации и агентам — `../domain_model/Access-questions.md` и `../domain_model/Access-decisions.md`.
